# Organic Farming Website

## Overview
This is a **responsive Organic Farming Website** built using **HTML** and **CSS**. The website provides information about various organic crops, including their **growth steps**, **health benefits**, and additional product-specific information.  

The website is designed with a clean, user-friendly layout and a **navigation bar present on every page** for easy access to all sections.

## Features
- **Homepage** with a welcoming design and navigation menu
- **Navigation bar** on every page containing: Home, Products, About, Contact
- **Products dropdown** with:
  - Beetroot, Carrot, Cabbage, Corn, Cauliflower, Ginger, Onion, Wheat
- Each product page includes:
  - Steps to grow the crop
  - Health benefits
  - **More info dropdown** with additional details about the product
- **About page** describing biological farming
- **Contact page** with provided contact information
- Fully **responsive design** for desktop and mobile
- Clean layout with background images and intuitive navigation

## Technologies Used
- **HTML5** – structure and content
- **CSS3** – styling, layout, and responsive design
- **Font Awesome** – icons for dropdown indicators
